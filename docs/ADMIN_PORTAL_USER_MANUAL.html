1. System Overview & Architecture

The XLurn Admin Portal provides unified administrative control over the enterprise video streaming and course authoring ecosystem. The platform supports tiered role administration with clear boundary separations between Super Admins and Author Admins.

RoleAccess LevelKey Capabilities
Super AdminGlobalPlatform configuration, author accounts, user directories, global catalog, billing, and system logs.
Author AdminScopedVideo uploads, multi-chapter course authoring, student engagement monitoring, and curriculum management.

2. Authentication & Session Security

The system enforces role-based authorization, RC4-encrypted credentials, and automated session timeouts.

Figure 2.1: XLurn Administrative Login Screen with Multi-Factor OTP and Role Shielding
Inactivity Guard: If no keyboard or mouse interactions are detected across open tabs for 10 minutes, the session is terminated and redirects to the login screen.
